# Web2API Studio 浏览器扩展

此扩展把用户主动连接的模型网站专用标签接到本机服务。源代码包含在工作台交付包中。

1. 在 Chrome / Edge 扩展管理页打开开发者模式，加载当前包含 `manifest.json` 的文件夹。
2. 打开 `http://127.0.0.1:8765/#providers`，生成配对码并粘贴到扩展弹窗，保存配对。
3. 点击平台的“连接网站”，按网站允许访问权限。在新开的专用标签登录，保持浏览器与此标签运行。
4. 工作台显示就绪后，通过 UI 或项目 Key 调用。自定义网站请求使用配置的平台 ID 和 `model: "default"`。

扩展仅操作自己打开并记录的标签。它不读取其他聊天标签，不导出 Cookie / 登录 token，不尝试处理 CAPTCHA。服务地址固定为本机 8765。访问权限由用户逐网站授予；配对凭据保存在扩展自己的本机 storage 中，content script 无权读取。

每次任务将专用标签导航到配置的新对话入口，从空会话发送。请勿在这个标签手动起草对话。页面刷新、标签关闭、扩展重启中断、超时等情况会报告错误，不会重新发送提示词。仅在回传失败时重试交付已有结果。浏览器重启后，在扩展里重新连接平台。

2.0.1 修复：网页导航结束后继续等待输入框加载，最长等待 30 秒；等待期间不会发送提示词。遇到登录页面则立即提示登录。更新现有扩展后，请在扩展管理页点击该扩展的重新加载，再从扩展弹窗连接专用标签。

返回 PNG / JPEG / WebP 图片最大 20 MB，单次网页提交保存一张，网关为 n 串行提交后续请求。网页图片无法读取时需要从网页手动下载；扩展不保证原图像素或任意指定的尺寸。文字对话为非流式文本，模型和额度由实际网页账号决定。

自定义网站先在工作台配置选择器，再在扩展连接。需要直接可访问的输入框、发送按钮和回复区域；复杂 iframe / Shadow DOM 或特殊上传、下载可能需要额外代码适配。
